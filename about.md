## Replay Recall Assist

If you're a stat-grinder who wants to know when recall variants are available for any level you're playing, this mod is for you! Replay Recall Assist adds a button to LevelInfoLayer that, when clicked, will display a list of all recall variants available for the current level.

Supported recall variants include:

- <cc>Daily</c>
- <cl>Weekly</c>
- <cd>Event</c>
- <cr>Gauntlet</c>
- General version of a level (only if playing one of the variants)

**NOTE**: because of how the All Rated Levels spreadsheet is updated, this mod will not be able to show recall variants for levels that have not been added to the sheet. This may include daily, weekly, and event levels that were released over 9 days ago, as well as recently released gauntlets.
