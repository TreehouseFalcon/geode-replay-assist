# v0.3.0

- Recently-minted timed levels (Daily, Weekly, Event) are now immediately detected on game launch if they are present on the first page of their respective safe. Gauntlet evaluation has also been reworked and should be immediately detectable on game launch as well
- There is now a loading indicator displayed if some resources are still being loaded to determine the full set of available recalls for a level
- Renamed "Online" recall variant to "Browse"
- Undiscovered gauntlet variants render the same sprite to prevent spoilers
